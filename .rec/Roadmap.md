# Work and Release Planning

[Issues](https://github.com/HFDWKJ/APP-media-management/issues) own task scope and completion; [milestones](https://github.com/HFDWKJ/APP-media-management/milestones) group repository delivery scope. The owner’s private Project aggregates cross-repository planning. Specifications remain in `.doc`; actual release announcements remain in [GitHub Releases](https://github.com/HFDWKJ/APP-media-management/releases).
