# Repository Instructions

Preserve existing work, source data, historical imports, and repository visibility. Apply the owner's latest explicit task scope.

## Log conventions

Follow [MyProtocol logging policy](https://github.com/HFDWKJ/MyProtocol/blob/main/System-Conventions/Development/Logging.md). Store authored event, run, audit, migration, verification, and release/change logs in root `.log/` as `YYYYMMDDhh-concise-purpose.ext` (UTC, 24-hour hour; concise English purpose). New log and README prose defaults to EN-US unless the owner explicitly requests another language. Preserve raw data, stable IDs, frozen imports, and recovery evidence; indexes and live entity registries are not event logs. Never overwrite a collision; retain full timezone-aware timestamps and evidence links. This instruction supersedes earlier log-path and log/README language conventions.
